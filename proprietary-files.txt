# Radio FM.
#
# L'app FMRadio di LineageOS e quella di fabbrica sono la stessa app: la
# libreria registra i metodi nativi proprio per com/android/fmradio/FmNative,
# quindi le due si incastrano senza adattamenti. Il driver e' gia' in funzione
# (fmradio_drv.ko caricato, /dev/fm presente).
#
# Nella ROM di fabbrica la libreria sta in product/lib*, che da noi non esiste
# come partizione separata: la si installa in system. La partizione product non
# e' montata in /mnt/stock, ma extract-files.sh la legge dall'immagine con
# debugfs, che non chiede privilegi.
product/lib/libfmjni.so:system/lib/libfmjni.so
product/lib64/libfmjni.so:system/lib64/libfmjni.so

# Fino a settembre qui c'erano solo i dodici .jar del framework MediaTek: la
# vendor.img che il build produceva pesava 24 MB contro i 378 di quella vera,
# e non era un problema soltanto perche' non l'abbiamo mai installata -- il
# telefono ha sempre girato sul vendor di fabbrica.

# Lo e' diventato quando abbiamo costruito lo zip installabile: quello porta
# dentro tutte le partizioni, l'ha scritta, e il telefono e' rimasto senza le
# HAL MediaTek e senza la vendor_sepolicy.cil da 826 KB. Bootloop.
#
# Questi sono i 1622 file estratti dal vendor di fabbrica (i 12 collegamenti
# simbolici stanno in Android.mk, perche' un elenco di file non li esprime).

# ---------------------------------------------------------------------------
# LA PARTIZIONE VENDOR NON STA PIU' QUI
#
# Per un po' ci sono stati i 1622 file estratti dal vendor di fabbrica, uno per
# uno. Funzionava per costruire l'immagine, non per farla partire: il build
# installa comunque i propri moduli in /vendor -- le HAL che AOSP compila -- e
# ogni file su cui i due si sovrappongono va deciso a mano. Ne abbiamo decisi
# ottantatre' prima di accorgerci che il criterio "vince il piu' recente" e'
# sbagliato per tutto cio' che tocca il SoC, e che ogni scelta sbagliata si
# manifesta come un telefono fermo sul logo, senza un errore da leggere.
#
# Il vendor ora e' l'immagine di fabbrica, presa com'e':
#   BOARD_PREBUILT_VENDORIMAGE := vendor/doogee/s88pro/vendor.img
# Il build non la costruisce, la copia. E' identica bit per bit a quella che
# gira sul telefono da sempre, il che toglie di mezzo un'intera categoria di
# domande -- quali HAL, quali librerie, quali versioni -- a cui non serviva
# rispondere.
#
# Restano qui i soli file di system: i .jar del framework MediaTek, senza i
# quali mtkfusionrild resta in loop sul socket rild-oem.
# ---------------------------------------------------------------------------
